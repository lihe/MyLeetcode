# [LeetCode 470：用 Rand7() 实现 Rand10()](https://github.com/lihe/MyLeetcode/issues/28)

[470. 用 Rand7() 实现 Rand10()](https://leetcode.cn/problems/implement-rand10-using-rand7/)



# **一、先说结论：标准做法是「拒绝采样」**







## **思路**





rand7() 能均匀生成 1~7。

如果我们调用两次：



- 第一次决定“行”
- 第二次决定“列”





就能构造一个 **7 × 7 = 49** 个格子的均匀空间。



也就是：

```
1, 2, 3, ..., 49
```

每个数出现概率都一样。



------





## **为什么 49 有用？**





因为：

```
40 = 10 × 4
```

前 40 个数可以平均分成 10 组：



- 1,11,21,31 → 1
- 2,12,22,32 → 2
- …
- 10,20,30,40 → 10





所以：



- 如果生成的是 1~40，就可以均匀映射到 1~10
- 如果生成的是 41~49，就丢弃重来





这就叫 **拒绝采样**



------





# **二、标准代码**



```python
# The rand7() API is already defined for you.
# def rand7():
# @return a random integer in the range 1 to 7

class Solution:
    def rand10(self):
        while True:
            # 生成 1~49 的均匀随机数
            row = rand7()
            col = rand7()
            num = (row - 1) * 7 + col   # 1~49

            # 只取前 40 个
            if num <= 40:
                return (num - 1) % 10 + 1
```



------





# **三、为什么这样是均匀的？**





这是面试最爱问的点。





## **第一步：1~49为什么均匀？**







因为：



- row 有 7 种可能，等概率
- col 有 7 种可能，等概率
- 两次独立





所以 49 种组合：

```
(row, col)
```

每种概率都是：

```
1/7 × 1/7 = 1/49
```

因此映射出来的 1~49 是均匀的。



------





## **第二步：为什么1~40 -> 1~10也是均匀的？** 






因为前 40 个数里，每个余数类恰好出现 4 次：

```
(num - 1) % 10 + 1
```

例如：



- 1,11,21,31 都映射到 1
- 2,12,22,32 都映射到 2





每个结果都来自 4 个等概率数字，

所以 1~10 也是均匀的。



------





# **四、为什么不能直接% 10用在 49 上？** 







比如你直接写：

```
num = (rand7()-1) * 7 + rand7()   # 1~49
return (num - 1) % 10 + 1
```

这会有问题，因为：

```
49 不是 10 的倍数
```



- 有些数会出现 5 次
- 有些数只会出现 4 次





概率不相等，**不均匀**



所以必须只取 1~40。



------





# **五、期望调用次数是多少？**





每轮调用 rand7() 两次。



一轮成功的概率是：

```
40 / 49
```

所以期望轮数：

```
1 / (40/49) = 49/40
```

每轮 2 次 rand7()，所以期望调用次数：

```
2 × 49/40 = 98/40 = 2.45
```



------





# **六、进阶：还能更省吗？**





可以。

标准优化思路是：



> 被拒绝的 41~49 不要完全浪费，继续“回收利用”。



比如：



- 41~49 一共 9 个数
- 可以把它们重新映射成 1~9
- 再结合一次 rand7() 变成 1~63
- 再取前 60 个





这样能进一步降低 rand7() 的期望调用次数。



但在一般面试里，**先写出 49→40 的拒绝采样已经够了**。

如果面试官追问“还能优化吗”，你再讲“回收剩余样本空间”。



------





# **七、面试标准回答模板**





你可以这样说：



> 我会调用两次 rand7，构造一个 1 到 49 的均匀随机数空间。因为 40 是 10 的倍数，所以取前 40 个数并通过取模映射到 1 到 10，这样可以保证均匀性；而 41 到 49 的部分通过拒绝采样丢弃重试。



------





# **八、一句话总结**





> **rand7 → 49 个均匀状态 → 取前 40 个 → 均匀映射到 1~10**
