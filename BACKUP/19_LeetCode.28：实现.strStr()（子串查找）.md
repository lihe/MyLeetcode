# [LeetCode 28：实现 strStr()（子串查找）](https://github.com/lihe/MyLeetcode/issues/19)

[LeetCode 28：实现 strStr()（子串查找）](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/description/)


  

  

  ## **一、先给结论（最重要）**

  

  

  > **最简单正确解法：暴力匹配（双指针）**

  > **进阶高分解法：KMP（O(n+m)）**

  

  ------

  

  

  ## **二、解法一：暴力匹配（面试 100% 可过）**

  

  

  

  ### **思路（一句话）**

  

  

  > 从 haystack 的每个位置开始，尝试匹配 needle

  

  ------

  

  

  ### **代码（推荐你先写这个）**

  

  ```python
  class Solution:
      def strStr(self, haystack: str, needle: str) -> int:
          n, m = len(haystack), len(needle)
  
          for i in range(n - m + 1):
              if haystack[i:i+m] == needle:
                  return i
  
          return -1
  ```

  

  ------

  

  

  ### **示例推演**

  

  ```
  haystack = "sadbutsad"
  needle   = "sad"
  
  i = 0 → haystack[0:3] == "sad" ✅
  return 0
  ```

  

  ------

  

  

  ### **复杂度**

  

  

  - 时间复杂度：O(n * m)
  - 空间复杂度：O(1)

  

  

  📌 **在 LeetCode 数据范围内完全没问题**

  

  ------

  

  

  ## **三、解法二：KMP（面试进阶 / 算法岗位）**

  

  

  

  ### **核心思想（先理解，不背公式）**

  

  

  > **匹配失败时，不回退主串指针，而是利用已匹配的信息跳转模式串**

  

  ------

  

  

  ## **四、KMP 的完整实现（标准版）**

  

  ```python
  class Solution:
      def strStr(self, haystack: str, needle: str) -> int:
          if not needle:
              return 0
  
          # 1️⃣ 构建 next 数组
          next = [0] * len(needle)
          j = 0
          for i in range(1, len(needle)):
              while j > 0 and needle[i] != needle[j]:
                  j = next[j - 1]
              if needle[i] == needle[j]:
                  j += 1
              next[i] = j
  
          # 2️⃣ 匹配过程
          j = 0
          for i in range(len(haystack)):
              while j > 0 and haystack[i] != needle[j]:
                  j = next[j - 1]
              if haystack[i] == needle[j]:
                  j += 1
              if j == len(needle):
                  return i - j + 1
  
          return -1
  ```

  

  ------

  

  

  ## **五、KMP 的直觉解释**

  

  

  

  ### **1️⃣ next[i] 表示什么？**

  

  

  > needle[0:i] 中

  > **最长的「前缀 = 后缀」长度**

  

  ------

  

  

  ### **2️⃣ 为什么能跳？**

  

  

  因为你已经知道：

  ```
  needle[0:j-1] == haystack[i-j+1:i]
  ```

  所以失败时不需要从头再来。

  

  ------

  

  

  ## **六、什么时候用暴力？什么时候用 KMP？**

  

  | **场景**           | **推荐** |
  | ------------------ | -------- |
  | 面试白板 / 一面    | 暴力     |
  | 数据量不大         | 暴力     |
  | 明确问“优化 / KMP” | KMP      |
  | 算法岗 / 二面      | KMP      |

  📌 **99% 的面试：暴力 + 能解释即可过**

  

  ------

  ## **八、常见坑（一定注意）**

  

  

  

  ### **❌ 忘记边界**

  

  ```
  for i in range(n):   # ❌
  ```

  应为：

  ```
  for i in range(n - m + 1)
  ```

  ## **九、面试标准回答模板**

  

  

  > 我可以使用双指针的暴力匹配方法，从主串的每个位置尝试匹配模式串，时间复杂度是 O(nm)。如果需要优化，可以使用 KMP 算法，通过构建 next 数组在匹配失败时避免重复比较，将复杂度降到 O(n+m)。

  


#  **next 数组是怎么生成的**

##  **一、先给一句“人话定义”**





> **next[i] 表示：**

> **在 needle[0..i] 这个前缀里，**

> **最长的「相同前缀 = 后缀」的长度。**



但现在**先别记这句话**，我们用动画来“算”。



------





##  **二、你在干什么？**





想象你在做这件事👇



- 你拿着 **模式串 needle**
- 从左到右，一点点“扩建”
- 每加一个字符，就问自己一句话：





> **“我现在这段字符串，有没有一部分‘开头’和‘结尾’是一样的？”**



------





##  **三、动画主角登场**





在构建 next 时，有两个指针：

```
i：正在计算 next[i] 的位置（向右走）
j：当前能匹配上的“前缀长度”（会前进 / 后退）
```

👉 你可以把它想成：



- i：新字符登场
- j：老经验能用多少





------





##  **四、完整动画示例**





我们用 **最经典的例子**：

```
needle = "a b a b c"
index     0 1 2 3 4
```



------





###  ** 第 0 位（i = 0）**



```
a
```



- 只有一个字符
- 不可能有前缀 = 后缀



```
next[0] = 0
```

🎬 **画面**：啥都没发生



------





###  **第 1 位（i = 1）**



```
a b
```

前缀候选：a

后缀候选：b



❌ 不相等

```
next[1] = 0
```



------





###  **第 2 位（i = 2）**



```
a b a
```

现在你心里问：



> “我能不能把开头的 a

> 和结尾的 a 对上？”



✅ 能！

```
a b a

```

于是：

```
j = 1

```



------





###  **第 3 位（i = 3）**



```
a b a b
```

现在你已经知道：



- 前面有一个长度为 1 的可复用前缀：a





你试着继续：

```
a b a b

```

ab == ab ✅

```
j = 2
next[3] = 2
```



------





###  **第 4 位（i = 4）**



```

```

你想继续扩展：

```

当前字符：c
```

❌ 不匹配



------





####  **关键动画：**

####  **回退 j**





你不会傻傻地回到 0，而是：



> “我现在的 ab 不行，

> 那有没有更短的前缀还能用？”



于是你：

```
j = next[j - 1]   # j = next[1] = 0
```

再试一次：

```
a  vs  c
```

❌ 还是不行

```
next[4] = 0
```

##  **五、最终 next 数组**



```
index:  0 1 2 3 4
char:   a b a b c
next:   0 0 1 2 0
```

🎉 **这就是 KMP 的“记忆表”**



------





##  **六、把动画翻译成代码**



```python
def build_next(p):
    next = [0] * len(p)
    j = 0

    for i in range(1, len(p)):
        while j > 0 and p[i] != p[j]:
            j = next[j - 1]   # 🎬 回退

        if p[i] == p[j]:
            j += 1           # 🎬 扩展成功

        next[i] = j          # 🎬 记录结果

    return next
```



------





##  **七、你一定要记住的 3 条“动画规则”**





1️⃣ i 一直往右，不回头

2️⃣ j 表示“当前能复用的前缀长度”

3️⃣ 不匹配时，j = next[j-1]（向过去找经验）



------





##  **八、为什么 next 能加速匹配？**





> 因为它提前帮你算好了：

> **“失败时，模式串最多能滑到哪里而不白比”**



------







##  **动画设定（和前面保持一致）**





- **主串 haystack**：一条很长的跑道
- **模式串 needle**：一块会“自我反思”的脚印模板
- **next 数组**：模板上刻着的“滑动刻度线”
- **你**：负责把模板贴在跑道上对齐





------





##  **我们用这个经典例子**



```
haystack = "a b a b a b c"
needle   = "a b a b c"
next     = [0, 0, 1, 2, 0]
```

（这是你刚刚算出来的 next）



------





##  **第一幕：模板第一次贴上跑道**



```
跑道： a b a b a b c
模板： a b a b c
         ✔ ✔ ✔ ✔ ✘
```



- 前 4 个字符：完美匹配
- 第 5 个字符：c ≠ a → ❌ 失败





🎥 **镜头暂停**



------





##  **暴力算法会怎么做？**





> “算了，我不记得刚才的成功了。”

```
跑道： a b a b a b c
模板：   a b a b c
```



- 主串指针回退
- 已经对过的字符重新再比一次





👉 **浪费**



------





##  **KMP 登场：模板开始“反思”**





你低头看模板，模板自己说话了：



> “等等，我刚才成功匹配的是 abab

> 而 abab 里面，有一部分我自己是重复的。”



------





##  **第二幕：next 数组开始工作**







### **当前状态**





- 模式串在第 j = 4 位失败
- 你查刻度线：



```
j = next[j - 1] = next[3] = 2
```

🎥 **动画含义**：



> “别把模板抬走，

> 只需要把它滑到还能复用 ab 的位置。”



------





##  **模板“聪明滑动”**



```
跑道： a b a b a b c
模板：     a b a b c
           ↑
```

⚠️ 注意一个**关键点**：



👉 **主串指针 i 没有回退！**



你没有重新踩已经踩过的跑道。



------





##  **第三幕：继续对齐**



```
跑道： a b a b a b c
模板：     a b a b c
           ✔ ✔ ✔ ✔ ✔
```

这一次：



- 从 ab 开始
- 一路对到 c
- 🎉 **完全匹配成功**





------





##  **KMP 在这里返回答案**



```
匹配起点 = i - len(needle) + 1
```

你找到了 **needle 在 haystack 中第一次出现的位置**。



------





##  **用“人话”总结整个匹配过程**





> KMP 匹配时，主串指针永远向前走，模式串失败时不会回到起点，而是借助 next 数组，滑到一个“已经被证明可能成功”的位置。



------





##  **KMP 匹配阶段的 3 条“动画规则”（必背）**







### **规则 1️⃣**





**主串指针 i 从不回退**



------





### **规则 2️⃣**





**失败时只移动模式串指针 j**

```
j = next[j - 1]
```



------





### **规则 3️⃣**





**匹配成功就一起前进**

```
if haystack[i] == needle[j]:
    i += 1
    j += 1
```



------





##  **把动画翻译成代码**



```python
j = 0
for i in range(len(haystack)):
    while j > 0 and haystack[i] != needle[j]:
        j = next[j - 1]   # 🎬 模板滑动

    if haystack[i] == needle[j]:
        j += 1           # 🎬 对齐成功

    if j == len(needle):
        return i - j + 1
```



------





##  **为什么 KMP 一定是 O(n + m)？**





动画角度：



- 跑道（haystack）：

  👉 你只走一遍，不后退

- 模板（needle）：

  👉 滑动次数由 next 控制，总次数有限





👉 **没有“重复踩同一段跑道”**
