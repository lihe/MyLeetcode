# [Leetcode 150： 逆波兰表达式求值](https://github.com/lihe/MyLeetcode/issues/21)

[150. 逆波兰表达式求值](https://leetcode.cn/problems/evaluate-reverse-polish-notation/)




# **一、一句话核心思想**




> **遇到数字入栈，遇到运算符就弹出两个数计算，再把结果压回栈中。**



因为 **逆波兰表达式（后缀表达式）本身已经把“运算顺序”编码进顺序里了**，

所以：**不需要括号、不需要优先级判断**。



------





# **二、为什么一定要用栈？**





逆波兰表达式的结构是：

```
操作数 操作数 运算符
```

这意味着：



- 运算符 **总是作用在它前面的两个“最近结果”上**
- 最近的结果 → **后进先出**
- 👉 天然符合 **栈（LIFO）**





------

# **四、特别容易踩的坑**







## **1️⃣ 减法和除法的顺序不能反**



```
b = stack.pop()
a = stack.pop()
result = a - b   # 不是 b - a
```

同理：

```
result = a / b
```



------





## **2️⃣ Python 的除法问题（重点）**





题目要求：



> **向 0 截断**



Python 的 // 是 **向下取整**，不符合要求！





### **❌ 错误写法**



```
a // b
```



### **✅ 正确写法**



```
int(a / b)
```

因为 int() 是 **向 0 截断**



------





# **五、标准 Python 解法**



```python 
class Solution:
    def evalRPN(self, tokens: list[str]) -> int:
        stack = []
        
        for token in tokens:
            if token not in {"+", "-", "*", "/"}:
                stack.append(int(token))
            else:
                b = stack.pop()
                a = stack.pop()
                
                if token == "+":
                    stack.append(a + b)
                elif token == "-":
                    stack.append(a - b)
                elif token == "*":
                    stack.append(a * b)
                else:  # "/"
                    stack.append(int(a / b))  # 向 0 截断
        
        return stack[0]
```

### **规则 1️⃣**





**数字 → 直接进 nums 栈**



------





### **规则 2️⃣**





**运算符 → 看优先级，能算就算**

```

```

### **规则 3️⃣（最关键）**





**遇到右括号 ) → 一直算到左括号 (**

# **五、运算符优先级表**



```
* /  优先级高
+ -  优先级低
(    最低（阻断计算）
```

# **七、标准 Python 代码**



```python 
class Solution:
    def calculate(self, s: str) -> int:
        nums = []
        ops = []

        def priority(op):
            if op in ('+', '-'):
                return 1
            if op in ('*', '/'):
                return 2
            return 0

        def calc():
            b = nums.pop()
            a = nums.pop()
            op = ops.pop()
            if op == '+':
                nums.append(a + b)
            elif op == '-':
                nums.append(a - b)
            elif op == '*':
                nums.append(a * b)
            else:
                nums.append(int(a / b))  # 向 0 取整

        i = 0
        while i < len(s):
            if s[i] == ' ':
                i += 1
            elif s[i].isdigit():
                num = 0
                while i < len(s) and s[i].isdigit():
                    num = num * 10 + int(s[i])
                    i += 1
                nums.append(num)
            elif s[i] == '(':
                ops.append(s[i])
                i += 1
            elif s[i] == ')':
                while ops and ops[-1] != '(':
                    calc()
                ops.pop()  # 弹出 '('
                i += 1
            else:
                while ops and priority(ops[-1]) >= priority(s[i]):
                    calc()
                ops.append(s[i])
                i += 1

        while ops:
            calc()

        return nums[0]
```

# **八、面试常见追问**







### **Q1：为什么要两个栈？**





> 一个栈无法同时处理 **数值顺序 + 运算符优先级 + 括号结构**



------





### **Q2：能不能不用栈？**





> 本质还是递归，栈只是把递归**显式化**



------





### **Q3：为什么括号能“阻断计算”？**





> 因为 ( 的优先级最低，直到遇到 )



------





# **九、面试一句话终极总结**





> 使用数字栈和运算符栈遍历字符串，数字直接入栈；运算符根据优先级进行计算；遇到右括号时计算到左括号为止，最终栈中结果即为表达式值。
