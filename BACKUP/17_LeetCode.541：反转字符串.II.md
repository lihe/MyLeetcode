# [LeetCode 541：反转字符串 II](https://github.com/lihe/MyLeetcode/issues/17)

[LeetCode 541：反转字符串 II](https://leetcode.cn/problems/reverse-string-ii/)



------





## **一、题意快速翻译**





> 从字符串起始位置开始，每 **2k** 个字符为一组，**只反转这一组中的前 k 个字符**，其余按规则处理直到结束。



------





## **二、核心规则拆解**





对字符串从左到右，每次看 **2k** 个字符：



1. **剩余字符 < k**

   

   - 👉 **全部反转**

   

2. **k ≤ 剩余字符 < 2k**

   

   - 👉 **只反转前 k 个**
   - 👉 后面的保持不变

   

3. **剩余字符 ≥ 2k**

   

   - 👉 **反转前 k 个**
   - 👉 后 k 个不动

   





------





## **三、算法思路**







### **思路关键词**





- 步长：2k
- 操作对象：[i, i+k)
- 原地 or 转 list 处理都可以







### **步骤**





1. 把字符串转成字符数组（方便修改）
2. 从 i = 0 开始，每次 i += 2k
3. 对区间 [i, min(i+k, n)) 做反转





------





## **四、Python 标准实现（面试推荐写法）**



``` Python
def reverseStr(s: str, k: int) -> str:
    s = list(s)
    n = len(s)

    for i in range(0, n, 2 * k):
        # 反转 [i, i+k)
        s[i:i+k] = reversed(s[i:i+k])

    return "".join(s)
```



------





## **五、为什么这一行就够了？**



```
s[i:i+k] = reversed(s[i:i+k])
```

因为：



- Python 切片 **自动处理越界**

- 当剩余字符：

  

  - < k → 切片只取剩余部分（全部反转）
  - ≥ k → 正好反转前 k 个

  

- 完美覆盖所有题目条件 ✅





------





## **六、示例走一遍（加深理解）**







### **示例**



```
s = "abcdefg", k = 2
```



### **过程**





- i = 0 → "ab" 反转 → "ba"
- i = 4 → "ef" 反转 → "fe"
- 剩余 "g" < k → 全反转（还是 "g"）







### **结果**



```
"bacdfeg"
```

## **七、复杂度分析**





- **时间复杂度**：O(n)

- **空间复杂度**：

  

  - Python：O(n)（字符串不可变）
  - 若允许原地字符数组：O(1) 额外空间

## **八、面试官级总结**





> 本题通过每次以 2k 为步长遍历字符串，并对每一段的前 k 个字符进行反转即可。利用切片和越界特性可以统一处理所有边界情况，时间复杂度为 O(n)，实现简洁且高效。
