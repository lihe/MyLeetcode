# [LeetCode 142：环形链表 II（找环的入口）](https://github.com/lihe/MyLeetcode/issues/16)

https://leetcode.cn/problems/linked-list-cycle-ii/

## **一、先给结论**





> **先用快慢指针判断是否有环；**

> **若有环，让一个指针从头节点出发，另一个从相遇点出发，**

> **两者每次走一步，再次相遇的节点就是环的入口。**



------





## **二、标准解法（O(n) 时间 + O(1) 空间）**



```python
class Solution:
    def detectCycle(self, head):
        slow = fast = head

        # 1️⃣ 先判断是否有环
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                break
        else:
            # 没有环
            return None

        # 2️⃣ 找环的入口
        slow = head
        while slow is not fast:
            slow = slow.next
            fast = fast.next

        return slow
```

✔ 不修改链表

✔ 不用额外空间

✔ 满足题目进阶要求



------





## **三、为什么“重新从头走”就能找到入口？（这是灵魂）**







### **定义几个距离（非常关键）**





假设：

```
head → … → 入环点 → … → 相遇点 → … → 入环点
```

定义：



- a：头节点 → 入环点 的距离
- b：入环点 → 相遇点 的距离
- c：相遇点 → 入环点 的距离
- 环长度：b + c





------





### **快慢指针第一次相遇时，发生了什么？**





- 慢指针走了：a + b
- 快指针走了：a + b + k(b + c)（多转了 k 圈）





因为快指针速度是慢指针的 **2 倍**：



2(a + b) = a + b + k(b + c)



整理：



a = k(b + c) - b = (k-1)(b+c) + c



👉 **关键结论：**



> a ≡ c (mod 环长度)



也就是说：



- 从 **头节点走 a 步**
- 从 **相遇点走 c 步**





👉 **都会到达入环点**



------





## **四、这就是第二阶段的逻辑**



```
slow = head      # 走 a 步
fast = 相遇点    # 走 c 步

while slow != fast:
    slow = slow.next
    fast = fast.next
```

两者 **必然在入环点相遇**。



------





## **五、手动推演一遍**





示例：

```
1 → 2 → 3 → 4 → 5
          ↑       ↓
          ← ← ← ←
```



- 第一次相遇在 4
- slow 回到 1
- fast 留在 4





走：

| **步数** | **slow** | **fast** |
| -------- | -------- | -------- |
| 1        | 2        | 5        |
| 2        | 3        | 3 ✅      |

👉 3 是入环点

## **八、常见翻车点（非常重要）**







### **❌ 错误 1：没用** 

### **else**

###  **判断无环**



```
while fast and fast.next:
    ...
# 直接进入第二阶段 ❌
```

👉 如果无环会死循环 / 空指针



------





### **❌ 错误 2：第二阶段快指针没动**



```
slow = head
# fast 不动 ❌
```

👉 永远不相遇



------





### **❌ 错误 3：用值判断**



```
slow.val == fast.val  # ❌
```

👉 必须是节点引用比较



------
