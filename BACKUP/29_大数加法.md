# [大数加法](https://github.com/lihe/MyLeetcode/issues/29)

这题本质上就是：**手动模拟竖式加法**。



因为题目不让你：



- 直接 int(num1) + int(num2)
- 用大整数库





所以你就要像小学算加法一样，从**最低位往高位**一位一位加。



------





# **一、核心思路（一句话）**





> **从两个字符串的末尾开始，逐位相加，维护进位 carry。**



------





# **二、为什么要从后往前？**





因为十进制加法是：



- 先算个位
- 再算十位
- 再算百位





例如：

```
  123
+ 789
-----
  912
```

是从右往左算的。



字符串里：



- 最右边是最低位
- 最左边是最高位





所以要从末尾开始遍历。



------





# **三、算法流程**





设两个指针：



- i 指向 num1 最后一个字符
- j 指向 num2 最后一个字符





再维护：



- carry：进位
- res：结果字符列表





每一步做：



1. 取当前位数字
2. 加上进位
3. 结果的个位加入答案
4. 十位变成新的进位
5. 指针左移





最后如果还有进位，再补一个。



------





# **四、代码实现**



```python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i = len(num1) - 1
        j = len(num2) - 1
        carry = 0
        res = []

        while i >= 0 or j >= 0 or carry:
            x = ord(num1[i]) - ord('0') if i >= 0 else 0
            y = ord(num2[j]) - ord('0') if j >= 0 else 0

            total = x + y + carry
            res.append(str(total % 10))
            carry = total // 10

            i -= 1
            j -= 1

        return ''.join(res[::-1])
```



------





# **五、代码逐行解释**







## **1. 初始化指针**



```
i = len(num1) - 1
j = len(num2) - 1
```

指向两个字符串最后一位。



------





## **2. 进位和结果**



```
carry = 0
res = []
```



- carry 表示上一位传来的进位
- res 用来存结果





------





## **3. 循环条件**



```
while i >= 0 or j >= 0 or carry:
```

只要满足一个条件就继续：



- num1 还有没处理的位
- num2 还有没处理的位
- 还有进位没处理完





------





## **4. 取当前位**



```
x = ord(num1[i]) - ord('0') if i >= 0 else 0
y = ord(num2[j]) - ord('0') if j >= 0 else 0
```

这里的意思是：



- 如果指针没越界，就取当前字符对应的数字
- 如果越界了，就当作 0





比如：

```
ord('7') - ord('0')  # 7
```



------





## **5. 当前位求和**



```
total = x + y + carry
```



------





## **6. 当前位结果**



```
res.append(str(total % 10))
```

例如：



- 17 % 10 = 7
- 当前位写 7





------





## **7. 更新进位**



```
carry = total // 10
```

例如：



- 17 // 10 = 1
- 进位变成 1





------





## **8. 指针左移**



```
i -= 1
j -= 1
```



------





## **9. 最后翻转结果**





因为我们是从低位往高位加，所以结果是倒着放进 res 的。

```
return ''.join(res[::-1])
```



------





# **六、举个例子**







## **输入**



```
num1 = "456"
num2 = "77"
```



------





## **过程**







### **第一步**





- 6 + 7 + 0 = 13
- 当前位 3
- 进位 1





res = ['3']



------





### **第二步**





- 5 + 7 + 1 = 13
- 当前位 3
- 进位 1





res = ['3', '3']



------





### **第三步**





- 4 + 0 + 1 = 5
- 当前位 5
- 进位 0





res = ['3', '3', '5']



------





### **最后翻转**



```
"533"[::-1] = "533"
```

结果：

```
"533"
```



------





# **七、时间复杂度**





设：



- n = len(num1)
- m = len(num2)





每一位只处理一次，所以：



- 时间复杂度：O(max(n, m))
- 空间复杂度：O(max(n, m))





------





# **八、这题为什么叫“大数相加”？**





因为如果字符串非常长，比如几千位：

```
999999999999999999999999999999999999999...
```

已经超出了普通整数类型能表示的范围。



所以不能直接转 int，只能按字符串手动处理。



------





# **九、面试回答模板**





你可以这样说：



> 这题可以模拟十进制竖式加法。从两个字符串末尾开始逐位相加，用 carry 保存进位。每次把当前位结果加入答案数组，最后再反转得到最终结果。这样可以避免使用大整数库，时间复杂度是 O(max(n,m))。



------





# **十、补充：更简洁版本**





如果你想写得更短一点：

```python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i, j = len(num1) - 1, len(num2) - 1
        carry = 0
        ans = []

        while i >= 0 or j >= 0 or carry:
            a = int(num1[i]) if i >= 0 else 0
            b = int(num2[j]) if j >= 0 else 0
            s = a + b + carry
            ans.append(str(s % 10))
            carry = s // 10
            i -= 1
            j -= 1

        return ''.join(reversed(ans))
```
