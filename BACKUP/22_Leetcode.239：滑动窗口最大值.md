# [Leetcode 239：滑动窗口最大值](https://github.com/lihe/MyLeetcode/issues/22)


[239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)


## **一、为什么暴力不行？**





每个窗口都算最大值：



- 一个窗口大小 k
- 每次找最大值要 O(k)
- 一共 n 个窗口





👉 总复杂度：O(nk)

当 n = 10^5、k = 10^5，直接 **TLE**



------





## **二、核心思想**





> **用一个“单调递减的双端队列”，**

> **队头永远是当前窗口的最大值**



我们存的不是值，而是 **下标 index**。



------





## **三、这个队列长什么样？**





队列里满足两个条件：





### **条件 1️⃣：从队头到队尾，值是**

### **递减的**



```
nums[queue[0]] ≥ nums[queue[1]] ≥ nums[queue[2]] ...
```



### **条件 2️⃣：队头的下标，一定在当前窗口内**





------





## **四、为什么能这样做？**







### **❓ 为什么比新数小的可以直接删？**





假设你遇到一个新数 x：



- 队尾元素比 x 小

- 那它：

  

  - 更早进入窗口
  - 数值还更小
  - 未来永远不可能成为最大值

  





👉 **直接淘汰**



------





## **五、规则总结**





对每个 nums[i]：





### **规则 1️⃣：维护单调性（从队尾删）**



```
while queue 非空 且 nums[queue[-1]] <= nums[i]:
    queue.pop()
```



### **规则 2️⃣：新元素入队（下标）**



```
queue.append(i)
```



### **规则 3️⃣：窗口左边界移出时，从队头删**



```
if queue[0] < i - k + 1:
    queue.popleft()
```



### **规则 4️⃣：窗口形成后，记录最大值**



```
nums[queue[0]]
```



------





## **六、动画式走一遍示例（非常关键）**



```
nums = [1,3,-1,-3,5,3,6,7]
k = 3
```

我们只看队列里**对应的值**（实际存的是下标）。



------





### **i = 0，nums[i]=1**



```
queue = [1]
```



------





### **i = 1，nums[i]=3**





- 3 > 1 → 1 出局



```
queue = [3]
```



------





### **i = 2，nums[i]=-1**



```
queue = [3, -1]
```

窗口形成（i >= 2）

最大值 = **3**



------





### **i = 3，nums[i]=-3**



```
queue = [3, -1, -3]
```

窗口左边界是 1，3 还在

最大值 = **3**



------





### **i = 4，nums[i]=5**





- 5 > -3 → -3 出
- 5 > -1 → -1 出
- 5 > 3 → 3 出



```
queue = [5]
```

最大值 = **5**



------



后面同理，最终得到：

```
[3, 3, 5, 5, 6, 7]
```



------





## **七、标准 Python 代码（必须会写）**



```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        q = deque()   # 存下标
        res = []

        for i in range(len(nums)):
            # 1️⃣ 维护单调递减
            while q and nums[q[-1]] <= nums[i]:
                q.pop()

            q.append(i)

            # 2️⃣ 移除窗口外的元素
            if q[0] < i - k + 1:
                q.popleft()

            # 3️⃣ 记录窗口最大值
            if i >= k - 1:
                res.append(nums[q[0]])

        return res
```



------





## **八、复杂度分析**





- **时间复杂度：O(n)**

  

  - 每个元素最多进队一次、出队一次

  

- **空间复杂度：O(k)**





------





## **九、面试一句话总结**





> 使用单调递减队列维护窗口内可能成为最大值的元素下标，队头始终为当前窗口最大值。每个元素只进出队列一次，因此时间复杂度为 O(n)。
