# [LeetCode 160：相交链表](https://github.com/lihe/MyLeetcode/issues/15)

https://leetcode.cn/problems/intersection-of-two-linked-lists/submissions/687890317/




## **一、先给结论**





> **用两个指针分别从 headA 和 headB 出发，走到末尾后切换到另一条链表的头，如果两链表相交，两个指针一定会在交点相遇；如果不相交，最终都会走到 null。**





------





## **二、最优解法：双指针「换头法」（O(n) + O(1)）**







### **标准代码（面试级）**



```python 
class Solution:
    def getIntersectionNode(self, headA, headB):
        pA, pB = headA, headB

        while pA is not pB:
            pA = pA.next if pA else headB
            pB = pB.next if pB else headA

        return pA  # 可能是相交节点，也可能是 None
```

✔ 不改链表结构

✔ 不用额外空间

✔ 一趟“等效遍历”



------





## **三、为什么这个方法一定成立？**







### **关键事实（一定要理解）**





- 如果两个链表相交

  👉 **相交之后的所有节点是完全共享的**

- 两条链表长度可能不同

  👉 前半段“独占部分”长度不同





------





### **核心思想：**

### **让两指针“走过相同的总路程”**





设：



- 链表 A 长度 = a + c
- 链表 B 长度 = b + c
- c 是公共尾部长度







#### **指针走的路径是：**



```
pA: A → B
pB: B → A
```

两者总路程都是：

```
a + c + b
```

👉 **在第二次进入公共尾部时，一定同时到达交点**



------





## **四、用图形直觉理解**





假设：

```
A: a1 → a2 → c1 → c2 → c3
B: b1 → b2 → b3 → c1 → c2 → c3
```

第一次走：



- pA 先到 c1
- pB 还没到





换头后：



- pA 走 b1 b2 b3
- pB 走 a1 a2





👉 当两者都进入 c1 时：

```
pA == pB == c1
```



------





## **五、如果不相交会发生什么？**



```
A: a1 → a2 → a3 → None
B: b1 → b2 → None
```

路径：



- pA: A → B → None
- pB: B → A → None





👉 **最终同时为 None**

```
return None
```

符合题意。



------





## **六、为什么不能用「值相等」判断？**





题目明确强调：



> **相交是“节点相同”，不是“值相同”**



所以判断必须是：

```
pA is pB
```

而不是：

```
pA.val == pB.val  # ❌
```



------





## **七、为什么不能改链表结构？**





题目要求：



> **返回结果后，链表必须保持原始结构**



所以以下做法全部 ❌：



- 改 next
- 反转链表
- 做标记





------





## **八、常见错误（高频翻车点）**







### **❌ 错误 1：只遍历一次**



```
while pA and pB:
```

👉 长度不同，永远对不齐



------





### **❌ 错误 2：不换头**



```
pA = pA.next
pB = pB.next
```

👉 只能对齐长度相同的链表



------





### **❌ 错误 3：用 set / hash**



```
visited = set()
```

👉 空间复杂度 O(n)，不满足进阶



------





## **九、另一种解法（了解即可）：长度对齐法**





思路：



1. 分别算长度
2. 长链表先走差值
3. 同步走找交点





✔ 正确

❌ 代码更长

❌ 两次遍历



👉 **不如换头法优雅**



------





## **十、面试标准回答模板**





> 使用双指针的方法，让两个指针分别从两条链表的头开始遍历，当走到末尾时切换到另一条链表的头。这样可以让两个指针走过相同的总路径长度，如果链表相交，它们一定会在交点相遇；如果不相交，则最终都会指向 null。
