# [这题是 LeetCode 61：旋转链表 (Rotate List)](https://github.com/lihe/MyLeetcode/issues/36)

[61. 旋转链表](https://leetcode.cn/problems/rotate-list/)

题意：



> 将链表 **向右旋转 k 次**。



例如：

```
1 → 2 → 3 → 4 → 5
```

右旋一次：

```
5 → 1 → 2 → 3 → 4
```

右旋两次：

```
4 → 5 → 1 → 2 → 3
```



------





# **一、关键观察（非常重要）**





假设链表长度是 n。



如果：

```
k >= n
```

那么：

```
旋转 n 次 = 没变化
```

所以我们只需要：

```
k = k % n
```

例如：

```
n = 3
k = 4

k % n = 1
```

只需要旋转 **1 次**。



------





# **二、核心思路**





核心操作：

```
1 → 2 → 3 → 4 → 5
```

如果右旋 k = 2



新头节点是：

```
第 n-k 个节点后面
```

即：

```
n = 5
k = 2

new head = 第 4 个节点
```

结果：

```
4 → 5 → 1 → 2 → 3
```



------





# **三、算法步骤**







### **第一步：计算链表长度**





遍历链表：

```
1 → 2 → 3 → 4 → 5
```

得到：

```
n = 5
```

并记录 **尾节点 tail**。



------





### **第二步：k 取余**



```
k = k % n
```

如果：

```
k = 0
```

直接返回原链表。



------





### **第三步：形成环**





把链表变成：

```
1 → 2 → 3 → 4 → 5
↑               ↓
└───────────────┘
```

代码：

```
tail.next = head
```



------





### **第四步：找到新的尾节点**





新的尾节点是：

```
第 n-k 个节点
```

例如：

```
n = 5
k = 2
```

新尾节点：

```
第 3 个节点
```



------





### **第五步：断开环**





新头节点：

```
new_head = new_tail.next
```

然后：

```
new_tail.next = None
```



------





# **四、图解**





原链表：

```
1 → 2 → 3 → 4 → 5
```

变成环：

```
1 → 2 → 3 → 4 → 5
↑               ↓
└───────────────┘
```

找到新尾节点：

```
1 → 2 → 3 → 4 → 5
        ↑
     new_tail
```

断开：

```
4 → 5 → 1 → 2 → 3
```



------





# **五、完整代码**



```python
class Solution:
    def rotateRight(self, head, k):
        if not head or not head.next or k == 0:
            return head

        # 1. 计算长度
        n = 1
        tail = head

        while tail.next:
            tail = tail.next
            n += 1

        # 2. k 取余
        k = k % n
        if k == 0:
            return head

        # 3. 形成环
        tail.next = head

        # 4. 找新尾节点
        steps = n - k
        new_tail = head

        for _ in range(steps - 1):
            new_tail = new_tail.next

        # 5. 断开
        new_head = new_tail.next
        new_tail.next = None

        return new_head
```
